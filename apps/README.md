# 🧩 Apps Project

This repository contains all application groups related to the **Andromeda Project**. Each family of applications serves a specific purpose and collaborates with others to deliver complete system functionality.

---

## 📁 Folder Structure

- **`/andromeda/`**  
  Server-side applications focused on authorization and authentication, forming the core of the Andromeda ecosystem.

- **`/nebula/`**  
  Main user-facing applications. Nebula handles most user-related interactions and business logic.

- **`/chess/`**  
  A set of applications dedicated to the Chess module.

- **`/element/`**  
  Applications for a custom trading card game service called Element.
