## Overview

Chess REST API provides backend services for managing chess-related data and workflows such as seasons, tournaments, games, players, titles, and rankings. It exposes a documented HTTP API and includes observability, security, and automation tooling for production use.

## Built With

- Languages and Runtime
  - Java 21 (SDK 21)
  - Maven (build system)

- Frameworks and Libraries
  - Spring Boot 3.3.x (core, Web, Validation, AOP)
  - Spring Security
  - Spring HATEOAS
  - Spring Data JPA
  - Hibernate ORM, Hibernate JCache + Ehcache
  - MapStruct (mapping)
  - springdoc-openapi (Swagger UI / OpenAPI)
  - Micrometer + Prometheus (metrics)
  - Logback + Logstash encoder (structured logging)
  - Apache HttpClient 5
  - JSON Web Tokens (jjwt)

- Database
  - MariaDB (JDBC driver)

- Testing
  - spring-boot-starter-test, spring-security-test, junit5, mockito

- Tooling / CI
  - Jenkins (pipeline)
  - Qodana (static analysis)

## Project Directory Structure

A quick overview of the repository layout and what each directory is used for.

```
chess-rest-api/
├─ src/
│  ├─ main/
│  │  ├─ java/pl/derleta/chess/            # Application source code
│  │  │  ├─ config/                        # Spring configuration, servlet initializer
│  │  │  ├─ controller/                    # REST controllers and assemblers
│  │  │  ├─ domain/                        # Domain models and JPA entities (entity, model, view, etc.)
│  │  │  ├─ exceptions/                    # Custom exceptions
│  │  │  ├─ mapper/                        # MapStruct mappers
│  │  │  ├─ repository/                    # Spring Data JPA repositories
│  │  │  ├─ service/                       # Services and providers
│  │  │  ├─ step/                          # Step processing framework
│  │  │  └─ util/                          # Utilities and helpers
│  │  └─ resources/
│  │     └─ webapp/WEB-INF/                # Web resources (e.g., web.xml for WAR deployment)
│  └─ test/
│     ├─ java/pl/derleta/chess/            # Unit and integration tests
│     └─ resources/                        # Test resources
├─ info/                                   # Project docs (CHANGELOG, HELP, JENKINS, STEP, etc.)
├─ htmlReport/                              # Local JaCoCo coverage HTML report (if generated)
├─ target/                                  # Build outputs (generated by Maven; safe to delete)
├─ pom.xml                                  # Maven project definition and dependencies
├─ qodana.yaml                              # Qodana static analysis configuration
├─ mvnw, mvnw.cmd                           # Maven wrapper scripts
└─ chess-rest-api.iml                       # IDE project file
```

Notes
- The `target/` directory is generated during builds and is not meant to be committed.
- The `htmlReport/` folder contains a locally generated coverage report. See Test Coverage Report below for details.
- The app is packaged as a WAR (see `packaging` in `pom.xml`) and includes `src/main/resources/webapp/WEB-INF` for servlet deployment metadata.

Tip: to print a directory tree locally, you can use:
```
tree -L 3 -I "target|.git"  # install 'tree' if not present
```

## Functional Features

- Manage seasons and steps (create, list, update, archive)
- Tournament lifecycle management (phases, pairings, results)
- Player registry with titles and global ranking data
- Game recording and results, with season save/export utilities
- HATEOAS-enabled resource representations
- OpenAPI-described REST endpoints

## Non-Functional Features

- Security with Spring Security and JWT
- Observability via Spring Boot Actuator and Prometheus metrics
- Structured JSON logging (Logstash encoder) for better log aggregation
- Caching with Ehcache and Hibernate second-level cache
- Externalized configuration via Spring Cloud Config
- API documentation via OpenAPI/Swagger UI
- CI-ready with Jenkins pipeline definition

## API Documentation

After running the app in localhost, the API documentation will be available at the following URLs:

- [Swagger UI](http://localhost:8555/swagger-ui/index.html)
- [OpenAPI JSON](http://localhost:8555/v3/api-docs)

Prometheus metric are available under:

- [Actuator](http://localhost:8555/actuator)
- [Prometheus](http://localhost:8555/actuator/prometheus)
