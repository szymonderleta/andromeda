# 🌠 Nebula Family Apps

This folder contains all applications from the **Nebula family**, which are part of the broader **Andromeda Project**. Each application serves a specific role and works in tandem with the others to provide core user-facing functionality.

---

## 📁 Folder Structure

- **`/nebula-rest-api/`**  
  Java 21 application built with Spring Boot and Hibernate. It provides a REST API for storing and managing general user settings and data.

- **`/nebula-front-app/`**  
  JavaScript application built with React. It includes frontend components and forms for:
    - User registration and login
    - Profile and avatar updates
    - Settings management
    - Password change and reset functionality
