# Apps Project

## About the Apps
This folder contains all Nebula family applications related to the [Andromeda Project]. Each application serves a specific purpose and works together to deliver the desired functionality of the project.

## Folder Structure
- **/nebula-rest-api/**: Contains a REST API application, written in Java 21 using Spring Boot and Hibernate frameworks, it contains endpoints that allows store general user settings and data.
- **/nebula-front-app/**: Contains a frontend home page application, written in JavaScript and React, that contains forms for regisration, login, update profile data and user avatar, update settings, resetting or change passwords.

## Technologies Used
- **Backend applications**: [Java (Spring, Hibernate ORM)]
- **Frontend applications**: [JavaScript (React), Python (Django)]
- **Communication**: REST API.
